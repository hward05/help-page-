📊 다중 데이터셋 시각화 도구 (Tkinter 기반)

이 도구는 최대 10개의 환경 센서 데이터를 동시에 불러와 필터링, 시각화, 통계 분석(T-test), 다항식 회귀선 계산 등 다양한 기능을 지원하는 Python 기반의 고급 GUI 분석 플랫폼입니다.

🛠 주요 기능 요약

기능설명
📁 파일 불러오기.txt, .csv, .xlsx 지원 (시트 선택 포함)
🎨 데이터 시각화최대 10개까지 Y, Y1 축 값 표현 가능
📐 다항식 회귀선AIC 기반 자동 차수 결정 (줌 시 자동 업데이트)
🧪 Welch’s T-Test두 데이터셋의 평균 비교
🔍 Z-점수 필터링이상치 제거 필터 (Y, Y1 별도 적용)
🔧 추세선 재생성줌 후 회귀선 자동 갱신, 버튼으로 리셋
🖊 점 정보 표기 기능점을 클릭 시 점의 x, y 정보 표시 기능 (ex. X:시간, Y:PM2.5)
💾 CSV 저장필터링된 데이터셋을 CSV로 저장 가능
🌐 Help 버튼GitHub Pages 문서 연결

📁 주요 코드 구성

parse_file(path)

  • .txt, .csv, .xlsx 파일을 통일된 pandas.DataFrame 형식으로 파싱
  • Timestamp 컬럼 자동 생성

plot_all()

  • 각 데이터셋을 필터링 및 시각화
  • Z-score 필터 적용
  • polyfit + AIC로 회귀선 자동 생성
  • 범례, 색상, 마커 구성
  • Zoom 및 Date/Time 옵션 UI 포함

find_best_poly_degree_aic(x, y)

  • AIC 기준으로 1~30차까지 polyfit 비교
  • 잔차 제곱합(RSS) + 복잡도 고려

on_zoom_release(event)

  • 줌 이후 현재 범위에서 다시 회귀선 계산
  • 기존 회귀선 제거 후 새로 그림

add_polynomial_fit(...)

  • polyfit 결과로 추세선 생성
  • Timestamp 타입인 경우 날짜 형식 변환

run_ttest()

  • Welch의 t-test로 두 데이터셋 비교
  • 평균과 p-value를 팝업으로 표시

export_filtered_data()

  • 날짜/시간 필터를 기반으로 CSV 저장
  • 자동 파일명 생성

clear_annotations()

  • 클릭으로 추가된 주석 모두 제거

reset_zoom()

  • 원래의 축 범위로 리셋

🖼 어노테이션 기능

  • 사용자가 점을 클릭하면 (x, y) 주석이 표시됨
  • 이 주석은 Clear 버튼으로 제거 가능
  • 다양한 데이터 타입에 대해 호환 가능
